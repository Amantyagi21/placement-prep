# AI Placement Preparation Assistant

A complete AI-powered platform to help students prepare for placements.

## Features
- Resume Analyzer + ATS Score
- Mock Interview Practice with AI Feedback
- DSA Practice with Solution Review
- HR Questions Generator
- Aptitude Practice (TCS, Infosys pattern)
- PDF Notes Summarizer
- Progress Dashboard

## Tech Stack
- Python
- Streamlit
- Groq API (LLaMA 3.3)
- SQLite
- PyPDF2
